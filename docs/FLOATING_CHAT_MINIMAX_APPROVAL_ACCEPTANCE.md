# Floating Chat MiniMax 与审批卡片人工验收

本验收只使用测试提示词，不记录、不展示任何真实 API Key。

## MiniMax-M3 回复可见内容

1. 在 Provider Center 选择已连接的 MiniMax CN Provider，模型选择 `MiniMax-M3`。
2. 打开 Floating Chat，输入：
   `从今往后你的名字就叫美美了`
3. 验收：
   - 聊天气泡只显示自然最终回复。
   - 气泡中不得出现 `thinking`、`reasoning`、`<think>`、`</think>`、`<thinking>`、`</thinking>` 或内部推理文本。

## 短回复路径

1. 在 Floating Chat 输入：
   `请只回复两个字：收到`
2. 验收：
   - 聊天气泡只显示最终回答，例如 `收到`。
   - 不显示内部推理或诊断占位文案。

## 普通聊天审批

1. 打开 Floating Chat。
2. 确认顶部显示已选择的 Provider / Model，例如 `MiniMax / MiniMax-M3`。
3. 发送普通聊天消息：
   `说说你可以为我做些什么`
4. 验收：
   - 只显示任务流和模型回复。
   - 不应出现 approval preview card 或审批按钮。
   - 不应出现 `审批预览`、`需要许可的动作会停在这里`、`已选择：总是允许` 常驻卡片。
   - 任务流可以显示轻量状态，但不能要求用户审批纯文本聊天。

## 需要权限的动作

1. 触发一个真正需要工具、文件、屏幕读取、系统操作或通知权限的动作。
2. 验收：
   - 审批卡片出现，并显示 `允许一次`、`拒绝`、`总是允许`。
   - 点击 `总是允许` 后，卡片应在约 1 秒内折叠或消失。
   - 选择 `总是允许` 后，后续同类动作不再显示完整审批卡片，只在任务流中显示轻量已允许状态。
