## Closeout Root Cause

The previous Real App smoke blocker had two causes:

- The DEBUG harness used the real permission prompt path. That could block App automation at `locationResolved` behind an `NSAlert`.
- Terminal activity/checkpoint writes could regress a `LocalDiscoveryWorkflowSnapshot` domain stage because generic checkpoint saves did not merge domain payloads and terminal fields.

The closeout also found one live model planner normalization gap: MiniMax returned provider-compatible draft variations such as natural-language category aliases, optional preference gaps in `missingInformation`, and preserved explicit location labels with `unknown` kind. These are now handled by deterministic normalization without accepting unknown categories or downgrading explicit location to current location.

## Fixes Verified

- DEBUG P9C App smoke harness auto-approves read-only capability prompts.
- `AgentCheckpointStore.save` merges same-run checkpoint data and preserves terminal/domain snapshot progression.
- `AgentTaskActivityStore` checkpoint rebuild preserves domain payloads, evidence IDs, result document, and UI revision.
- `ChatModel.stopGenerating()` catches up from EventHub and syncs cancelled activity bubbles.
- `LocalDiscoveryStructuredPlanner` canonicalizes supported category aliases, filters non-blocking optional missing gaps, and promotes preserved explicit labels to `explicitRegion`.
- MapKit search/route adapters have cancellation handlers.
